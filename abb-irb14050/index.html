Command reference and notes

Commands: MoveJ pN, vP; joint move, P = percent of max axis speed · MoveL pN, vV; straight-line TCP move, V = mm/s · SetDO doGrip, 0|1; · WaitDI diPart|diBin, 0|1; · WaitTime T; seconds · ENDPROC. Text after ! is a comment and is shown as the step explanation.

Before a program starts, the arm moves to the home pose (tool pointing down, above the pick spot) if it is not already there. The cycle timer runs while a program runs and counts finished programs.

Simplified model: joint limits and the reach of 559 mm come from the ABB IRB 14050 datasheet. Link lengths, the gripper, the base and the controller are approximations. There is no collision checking, and RAPID is only partly interpreted. Rated payload 0.5 kg.

How to operate the ABB IRB 14050 YuMi (OmniCore C30)

Read the chart from top to bottom. Rectangles are steps and buttons, diamonds are checks, and dashed lines show things that can happen at any time.

The steps are in the order you normally use them. Each step's button is named in capitals as it appears on the controller panel.

Buttons and operations

MODE MANUAL / AUTOMANUAL jogs and steps by hand at reduced speed. AUTO runs programs.
SERVO ON / OFFMotor power. Needed for any motion.
ENABLEDeadman switch. Hold it on to jog or step in MANUAL.
E-STOP / RESETE-STOP stops motion and servo and latches. RESET clears it; then press SERVO ON.
STARTAUTO mode only: starts the program (same as Run).
JOG tabJoint or Cartesian jog, Override, Home, Zero, Gripper, Record current.
POSITIONS / I/O / STATUSSaved positions, input and output toggles, and status: payload, cycle count, alarm log.
PROGRAM tabRun, Step, Pause, Stop, Edit. Sample and custom programs. Step runs one line in MANUAL with ENABLE held.
