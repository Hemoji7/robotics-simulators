Cartesian jog keeps the tool pointing in the direction it had when you started the jog. Manual mode limits TCP speed to 250 mm/s in this model. Jog needs MANUAL mode, motors on and the enabling device held.

Inputs are set by hand, as if a sensor changed. A line such as WaitDI diPart, 1; holds the program until its input matches. SetDO doGrip, 1; closes the gripper, or switches the vacuum on.

Toggling an input during a run is allowed, so you can release a waiting program.

Command reference and notes

Commands: MoveJ pN, vP; joint move, P = percent of max axis speed · MoveL pN, vV; straight-line TCP move, V = mm/s · SetDO doGrip, 0|1; · WaitDI diPart|diBin, 0|1; · WaitTime T; seconds · ENDPROC. Text after ! is a comment and is shown as the step explanation.

Before a program starts, the arm moves to the home pose (tool pointing down, above the pick spot) if it is not already there. The cycle timer runs while a program runs and counts finished programs.

Simplified model: joint limits and the reach of 559 mm come from the ABB IRB 14050 datasheet. Link lengths, the gripper, the base and the controller panel are approximations. There is no collision checking, and RAPID is only partly interpreted (see the commands above).
