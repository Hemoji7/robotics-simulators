Command reference and notes

Commands: J P[n] [%] joint move · L P[n] [mm/s] straight-line TCP move · GRIP OPEN|CLOSE · WAIT sec · SET DO[n] ON|OFF · WAIT DI[n] ON|OFF · END. Text after ; is a comment and is shown as the step explanation.

When a program starts, the arm first moves to the viewing pose (J1–J6 = 0, −20, 30, 0, −20, 0) if it is not already there.

Simplified model: no collision checking, and TP/KAREL are not interpreted. Body shapes are approximate. Geometry and joint limits are approximations, not Fanuc CAD data. Rated payload 4 kg (ER-4iA datasheet).

How to operate the Fanuc ER-4iA

Read the chart from top to bottom. Rectangles are steps and buttons, diamonds are checks, and dashed lines show things that can happen at any time.

The steps are in the order you normally use them. Each step's button is named in capitals as it appears on the controller panel.

Buttons and operations

MODE AUTO / T1 / T2AUTO runs programs with jog off. T1 is manual at 25% max speed. T2 is manual at full speed.
SERVO ON / OFFMotor power. Needed for any motion.
ENABLEDeadman switch. Hold it on to jog in T1 or T2, or to step a program.
E-STOP / RESETE-STOP stops motion and servo and latches. RESET clears it; then press SERVO ON.
STARTStarts the program in AUTO (same as Run).
JOG tabJoint or Cartesian jog, Override, Home, Zero, Gripper, Record current.
POSITIONS / I/O / STATUSSaved positions, input and output toggles, and status: payload, cycle count, alarm log.
PROGRAM tabRun, Step, Pause, Stop, Edit. Sample and custom programs (Save, Load, Delete, Download, Open).
