Command reference and notes

Commands: MOVJ Pnnn VJ=% joint move · MOVL Pnnn V=mm/s straight-line TCP move · DOUT OT#(1) ON|OFF · TIMER T=sec · WAIT IN#(n)=ON|OFF · NOP · END. Text after ' (or ;) is a comment and is shown as the step explanation.

When a program starts, the arm first moves to the reference pose (J1–J6 = 0, 0, 30, 0, −20, 0) if it is not already there. The cycle timer runs while a program runs and counts finished programs.

Simplified model: the arm is a generic small 6-axis robot, not a specific MOTOMAN model. There is no collision checking, and INFORM is only partly interpreted. Geometry and joint limits are placeholders, not Yaskawa data. The YRC1000micro supports robots up to about 12 kg; the rated payload used here is shown on the Status tab.
